# Codex Pulse 0.6.0

- 新增 TPS：使用本地官方输出计数和模型条目计时，详情标注「逐响应更新」。等待许可、多路并行、计时缺失、断线和过期样本均有独立状态，不混算或显示假 0。
- 小胶囊布局可在设置中自由选择「横向并排」或「上下布局」。横向宽 104 pt，上下保持 54 pt；悬停 / 固定仍采用 204 pt 横向长条。
- 付费点数默认小胶囊 1 位、展开 2 位，可独立调整为 0–3 位；空间不足时按原生宽度测量回退，完整余额仍可查看。
- TPS 需要已接入并信任的工作状态。只投影匹配会话的计数 / 计时，跳过聊天正文；该值为本地模型条目计时推导，不是逐 token 流式瞬时速度或服务器纯解码基准。

## English

- Adds generation TPS derived from official local output counters and model-item timing, updated per completed response. Waiting, parallel sessions, missing data, disconnects and expired samples remain explicit.
- Choose Side by side or Stacked for the compact capsule in Settings. Side by side is 104 pt wide; Stacked keeps the original 54 pt width. Hovered and pinned bars remain 204 pt horizontal bars.
- Configure credit precision independently: one decimal place for compact and two for expanded by default, adjustable from 0–3.
- TPS requires connected, trusted activity status. Only bounded counter/timing metadata is projected; conversation bodies are skipped. This is not a token-stream instantaneous or server decode benchmark.
