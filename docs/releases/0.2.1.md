# Codex Pulse 0.2.1

## 简体中文

- 重新设计展开卡片：窗口名称、剩余百分比和重置倒计时各显示一次，减少重复文字。
- 普通卡片按实际内容调整高度，不再出现多余滚动条；很多窗口超出屏幕时仍可滚动查看。
- 刷新、固定和收起集中到顶部；工作状态与更新时间保留在底部，0 次重置不再占位。
- 保留中英文、深浅色、未知额度、断线缓存和过期提示；常驻胶囊的形状与吸附行为保持一致。

此版本沿用经过签名的自动更新。

## English

- Redesigned the expanded quota card around the window name, remaining percentage, and reset countdown.
- Cards fit their content without unnecessary scrollbars. Long lists remain scrollable when they exceed the available screen height.
- Refresh, pin, and collapse actions share a compact header. Working status or update time appears in the footer; zero reset credits no longer occupy a row.
- Preserves Chinese/English, light/dark themes, unknown quota, cached/disconnected and stale states, and the existing compact capsule behavior.

This release uses the existing signed automatic update channel.
