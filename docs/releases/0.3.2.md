# Codex Pulse 0.3.2

## 简体中文

- 修复窗口跟随一顿一顿的问题：改为随显示器刷新同步位置，移动时不再反复重绘整张卡片。
- Codex 失焦后胶囊不再消失。胶囊保持在 Codex 窗口上方，Finder 等前方窗口可自然遮挡它；最小化和切换空间仍正确处理。
- 静止时降低位置查询频率，移动时恢复高频跟随；展开、收起与额度流光继续独立运行动画。
- 保留重叠边缘的吸附对象选择、细线外观和签名自动更新。

## English

- Smooth window following with display-synchronized updates. Moving the host no longer rebuilds the SwiftUI card.
- Keep the capsule attached when Codex loses focus. Foreground windows cover it together with its host; minimizing and Space changes still work.
- Reduce geometry queries while stationary and restore display-rate following during motion, independently of expansion and quota animations.
- Retains explicit target selection for overlapping edges, the thin capsule design, and signed automatic updates.
