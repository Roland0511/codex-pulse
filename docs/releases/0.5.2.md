# Codex Pulse 0.5.2

## 简体中文

- 改善短暂读取失败后的自动恢复：胶囊可见时约一分钟重试，重新显示过时或异常的数据时立即补刷；隐藏时继续使用有上限的退避。
- 加强刷新调度兜底，并在用户会话恢复时复核额度；仍遵守休眠暂停、请求去重和账户隔离，读取成功前保留缓存 / 过期标记。
- 54 pt 侧边标签在过期、连接异常、未登录、不可用或服务受限时显示静态橙色感叹号，降低旧数值对比度；百分比和充值点数仍完整可读，胶囊尺寸保持不变。
- 新数据成功返回后继续使用既有数值过渡，减少动态效果时直接更新；不推算额度，不新增账户修改接口。

## English

- Recover sooner after transient read failures: retry about once a minute while visible and revalidate outdated or failed data when the capsule becomes visible again. Hidden polling retains bounded backoff.
- Add a polling safeguard and revalidate quota when the user session becomes active. Preserve sleep suspension, request coalescing, account isolation and cached/stale labels until a successful read.
- Show a static orange warning symbol in the 54 pt edge label for stale, failed, signed-out, unavailable or restricted data. Dim unconfirmed values while keeping percentages and credits readable without changing capsule dimensions.
- Retain the existing transition for confirmed values and update directly with Reduce Motion. Do not estimate quota or add account-changing operations.
