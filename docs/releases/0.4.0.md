# Codex Pulse 0.4.0

## 简体中文

- 新增三档工作动效：标准保留流光，快速使用金色分叉电弧，超快使用更亮、更密集的双电弧与延迟分叉。
- 根据实际填充长度自适应：紧凑条改为单束电流，极短条改为中线脉冲；长条保留完整电弧，避免缩小时光效拥挤。
- 电弧采用程序化分形生成、连续扰动及前沿传播 / 尾部消散，金色根据胶囊实际背景适配。
- 修复 Codex 左内侧吸附轮廓偏移，以及白色流光头与填充条的垂直错位。
- 只读保存的默认速度配置；收到已确认工作会话的速度元数据后才覆盖。缺失或无法确认时据实回退，不读取聊天历史或正文。
- 保留工作特效的主动启用、状态门槛和系统减少动态效果设置，胶囊尺寸保持原样。

## English

- Add three work effects: the standard trace, fast gold forked arcs, and brighter, denser ultrafast twin arcs with delayed branches.
- Adapt to the actual filled length: compact tracks use one current, tiny tracks use an axis pulse, and long tracks retain full arcs.
- Generate arcs procedurally with fractal displacement, coherent motion, advancing fronts and fading tails. Gold adapts to the capsule background.
- Fix left inner-edge docking contours and vertical alignment between the white trace and quota fill.
- Read the saved default speed tier and use session metadata only when matched to confirmed work. Missing or unconfirmed values fall back honestly; no chat history or content is queried.
- Preserve opt-in work animation, activity gates, Reduce Motion, and existing capsule dimensions.
