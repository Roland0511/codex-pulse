# Codex Pulse 0.3.0

## 简体中文

- 胶囊现在可以吸附到 Codex 窗口左侧或右侧内边缘，并随窗口移动、缩放；最小化或离开 Codex 时暂时隐藏，返回后恢复。
- 当窗口与屏幕边缘重叠或接近时，松开拖动后选择吸附对象；Esc 取消并保持自由悬浮。位置菜单也提供明确的屏幕 / Codex 吸附命令。
- 保留细线胶囊、紧凑详情、签名自动更新。窗口跟随仅使用窗口位置元数据，无需新增辅助功能或屏幕录制权限。

## English

- Attach the capsule to either inner edge of a Codex window. It follows window movement and resizing, hides while Codex is minimized or inactive, and returns with Codex.
- When screen and window edges overlap or are close together, choose the attachment target after dropping. Escape leaves the capsule floating. The Position menu also provides explicit commands for both targets.
- Keeps the thin capsule, compact details, and signed automatic updates. Window following uses window geometry only and adds no Accessibility or Screen Recording permission request.
