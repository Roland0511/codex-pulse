# Codex Pulse 0.6.1

- 多个活动对话现在显示总 TPS，累加各路最近有效响应的速度，替代「多路」占位。
- 详情保留「逐响应更新」，显示参与汇总 / 生成中路数及许可等待路数。等待许可的会话不计入总值；缺样本时明确标注部分合计。
- 总值以最早计入响应判断新鲜度，保留值和部分值使用灰色与 `~`，单路超过 60 秒后从合计剔除；退出、断线和暂停及时更新。
- 横向 / 上下布局及点数精度设置保持原有选择。TPS 仍是各路逐响应本地计时派生速率之和，不是逐 token 瞬时测量。

## English

- Multiple active conversations now show Total TPS, summing each generating session’s latest valid response rate instead of a Multi placeholder.
- Details retain “Updates per response” and show contributing / generating sessions and permission waits. Waiting sessions are excluded; incomplete coverage is explicitly labeled as a partial sum.
- The oldest included response determines freshness. Retained or partial values are muted and prefixed with `~`; each sample expires after 60 seconds. Session exits, disconnects and pauses update the total.
- Existing layout and credit precision preferences are preserved. Total TPS is a sum of local per-response derived rates, not an instantaneous token-stream measurement.
