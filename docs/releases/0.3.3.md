# Codex Pulse 0.3.3

## 简体中文

- 修复 Codex 窗口静止时胶囊仍反复闪烁的问题，消除跨应用窗口层级争抢。
- 前方窗口按实际遮挡范围覆盖胶囊；未遮挡部分保留，被遮挡区域不拦截鼠标。
- 高速拖动时以经过窗口位移校验的鼠标事件即时跟随，减少胶囊脱节；内容拖动和缩放不会误触发。
- 保留移动时高频跟随、静止时低频查询，以及独立的展开和额度动画。

## English

- Fix capsule flicker while the Codex window is stationary by avoiding repeated cross-application reordering.
- Clip the capsule to its unobscured region and pass pointer events through covered areas.
- Follow verified host drags from pointer events to reduce lag at high speeds, without mistaking content drags or resizing for window movement.
- Preserve adaptive window following and independent expansion and quota animations.
