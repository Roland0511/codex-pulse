# Codex Pulse 使用指南

[English](USAGE.en.md) · [项目主页](../README.zh-CN.md)

## 安装与连接

从 [Releases](https://github.com/Roland0511/codex-pulse/releases/latest) 下载并打开通用架构 DMG，将应用拖入 Applications，弹出磁盘映像后启动。也提供 ZIP；应用与 DMG 均已签名、公证并附加票据，使用 `SHA256SUMS.txt` 核对下载文件。升级前先退出旧实例。要求 macOS 14+；当前已验证 Apple Silicon 实机，Intel 仅完成编译覆盖。

先安装并登录官方 Codex 应用或 CLI。Pulse 自动发现官方桌面包和常用 CLI 路径；失败时在「设置 → Codex 路径 → 选择」指定可执行文件。正式安装包无需 Python、Xcode 或本仓库。

## 读懂胶囊

主条显示所有可用窗口中最低的剩余百分比。点击查看每个窗口的实际时长、准确重置时间、服务提供的可用重置次数，以及最后成功更新时间。不假定 primary 是 5 小时或 secondary 是一周，缺失值保持未知。

任一订阅窗口耗尽且同一额度桶有充值余额时，主条自动显示剩余点数。小胶囊默认显示 1 位小数，如 `60.0k`、`1.2M`；悬停长条和展开详情默认显示 2 位，如 `60,123.45`。「设置 → 付费点数小数位」可分别选择 0–3 位，即时生效并保存。数值向下截取并保留末尾零，窄胶囊空间不足时减少精度或采用缩写；原始完整余额可在悬停提示和辅助说明中查看。正余额低于显示精度时显示 `<0.1` 等，不能显示为 0。点数模式的整条细线表示有可用余额，不代表余额比例；刷新确认订阅恢复后自动切回百分比。

连接失败会保留上次成功值并标记异常；超过三分钟未更新则标记过期。账户切换先清除旧数据。倒计时归零不等于额度已恢复，恢复反馈必须由新响应确认。

可见时每 60 秒刷新，主动隐藏时每五分钟刷新；打开详情仅在成功更新时间超过 15 秒时补刷。锁屏和睡眠暂停，恢复后补刷。请求合并、退避和服务保留时间有界，不启动推理任务探测额度。

## 移动、固定与键盘操作

将胶囊拖近屏幕或 Codex 窗口的左右内边缘，松开后吸附。窗口与屏幕边缘重叠或接近时，会弹出「选择吸附对象」菜单；选择屏幕或 Codex 窗口，Esc 取消并保持自由悬浮。菜单「位置」也提供四个明确的吸附入口。

选择 Codex 窗口后，胶囊随窗口移动、缩放；最小化时暂时隐藏，恢复窗口后重新出现；切换到其他 App 时仍留在 Codex 窗口上，与宿主一起被前方窗口遮挡。悬停伸出长条，图钉让鼠标离开后保持长条；点击查看详情。切回屏幕吸附会结束窗口跟随。

默认 `Control + Option + Command + P` 显示或隐藏，可在设置中选择按键及至少两个修饰键，冲突时会提示。菜单「展开额度详情」提供键盘焦点，Escape 收起详情；鼠标打开不抢焦点。

## 语言与外观

「设置 → 语言」提供跟随系统、简体中文和 English，即时切换并保存。跟随系统时中文环境显示简体中文，其它语言回退 English。日期使用所选语言、用户地区和本地时区；服务提供的额度桶名称不作自动翻译。

外观默认跟随 Codex 的深浅模式、背景、文字和强调色。系统、浅色、深色使用内置色板；不支持的 Codex 配置会回退系统主题并提示。

## 工作特效

新安装默认关闭。在设置中启用，审阅 12 条完整定义与写入位置后确认安装；其它钩子保留，并创建本地备份。接着启动 Codex CLI，输入 `/hooks`，审阅并信任全部 Pulse 定义，再回到设置点击「检查连接」。

12 条定义对应 Codex 独立的生命周期事件。大部分后台执行，会话结束事件按 Codex 行为同步执行，超时两秒。helper 跳过提示词、工具参数、回复和其它正文，只向本机发送白名单状态元数据。

全部定义启用并受信任、接收器可用后才播放持续流光。等待许可、结束、信号失效时停止；多个会话中任一个已确认工作时继续。系统减少动态效果时仅保留静态文字。新鲜额度快照确认消耗增加后，还可播放短暂补充提示。

关闭功能只移除 Pulse handlers。卸载前先关闭工作特效，再退出应用并移到废纸篓；本地备份保留以便恢复。

## 可选提醒与开机启动

两项默认关闭。启用提醒才申请系统通知许可，按周期对 20% / 10% 阈值去重。开机启动可能需要在系统设置「登录项」批准。启用后的系统通知交付与登录项验收仍留待后续，详见[验证记录](VERIFICATION.md)。

## 反馈问题

在 [Issues](https://github.com/Roland0511/codex-pulse/issues) 提供 macOS、架构、Pulse / Codex 版本、可见错误和复现步骤。不要上传原始账户响应、认证文件、聊天日志、未脱敏截图或钩子备份。安全漏洞使用[私密报告渠道](../SECURITY.md)。

## 生成速度（TPS）

设置中可开启「显示生成速度（TPS）」（默认开启）。吸附收起后，额度与速度横向并排；关闭恢复窄标签。需先按工作状态接入流程完成现有 hooks 的信任核对，TPS 不会替你安装或修改 Codex 配置。

详情标注「逐响应更新」与样本时间。TPS 来自官方输出 token 数和本地模型条目计时，包含推理输出；不是逐 token 流式瞬时速度。`~` 表示保留值或部分合计，同一活动轮次内保留上次有效样本，直至新样本替换或轮次结束；`···` 表示尚无读数，正在等待新响应。「等待」代表许可等待，多个活动会话显示总 TPS，按各路最近有效响应速度相加，排除许可等待；详情注明参与汇总 / 生成中路数、等待路数和「逐响应更新」。部分会话尚无有效样本时显示已知部分之和，明确标注「部分合计」；总值的新鲜度按最早计入响应判断；空闲、未连接与计时文件不可用不会显示假 0。缺字段的响应不会清除已有读数。中途启动时跳过首个不完整响应，再从下一完整响应恢复；历史读数持续标注为保留值。

在「小胶囊布局」中选择「横向并排」或「上下布局」，立即生效并保存。横向为 104 × 36 pt，上下保持 54 × 36 pt，上行额度、下行速度。悬停 / 固定长条始终横向；关闭再开启 TPS 会保留所选布局。

旧版 Pulse 的 `SessionEnd` 钩子若含 `async: true`，本修复版本会在启动 / 检查连接时自动备份并移除该无效选项，其他钩子保留；未安装用户不会被自动安装。若 Codex 提示定义已变更，请按现有「审阅信任」步骤确认，Pulse 不会代写信任记录。
